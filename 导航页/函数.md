# 函数 · 学习导航

> **说明**:函数是程序模块化的核心工具,也是数学中"映射"概念在编程中的直接体现.本模块从函数的基本概念出发,系统讲解函数的定义与调用,参数传递,作用域规则,`lambda` 匿名函数,递归设计,以及跨文件复用的模块导入机制,并通过综合案例展示函数在算法实现与数学问题求解中的应用.

#### 学习路径建议

##### 主线（必学)
1. **函数入门** → [[函数的基本概念]]:理解函数的结构与调用方式.
2. **函数进阶** → [[函数的使用]]:掌握多种参数传递方式与返回值.
3. **作用域** → [[变量的作用域]]:理解变量可见性与生命周期.
4. **递归思维** → [[递归函数]]:理解递归的数学本质（数学归纳法).

##### 支线（强化)
5. **匿名函数** → [[lambda函数]]:用于简单函数和高阶函数场景.
6. **跨文件复用** → [[模块与导入]]:把函数变成可导入的模块,消除复制粘贴.

##### 终点
7. **综合实战** → 综合应用:综合运用函数解决实际问题.

#### 核心概念思维导图

```
函数
├── 定义与调用
│   ├── def 函数名(参数):
│   ├── 形参 / 实参
│   └── return 返回值
├── 参数类型
│   ├── 位置参数
│   ├── 默认值参数
│   ├── 关键字参数
│   ├── *args（可变位置参数)
│   └── **kwargs（可变关键字参数)
├── 作用域
│   ├── 局部变量
│   ├── 全局变量
│   ├── global 声明
│   └── LEGB 规则
├── 匿名函数
│   └── lambda 参数: 表达式
├── 递归
│   ├── 终止条件（base case)
│   └── 递归步骤（recursive step)
└── 跨文件复用
    ├── import mod / from mod import func
    ├── __name__ == '__main__' 守卫
    ├── sys.path 搜索路径
    └── 命名冲突与模块命名规则
```

#### 扩展学习方向

- **高阶函数**:`map`,`filter`,`reduce`（函数作为参数或返回值)
- **装饰器**:在函数外部增强函数功能（如 `@lru_cache`)
- **生成器**:`yield` 关键字实现惰性求值
- **闭包**:函数内部定义函数,捕获外部变量
- **包与工程化**:`__init__.py`,相对导入,虚拟环境
