# 圣诞树.py · 字符画圣诞树(随机装饰)

> **摘要**:使用随机生成的字母和数字作为装饰,打印一棵圣诞树字符画.树干为随机数字,树冠由随机字母组成,中心有一颗星(Φ).

---

#### 💻 代码

```python
from random import *

def ranstr(x):
    s = ''
    n = int(x)
    for i in range(n):
        s += chr(int(randrange(ord('A'), ord('a') + 1)))
    return s

def ranstr1(x):
    s = ''
    n = int(x)
    for i in range(n):
        s += chr(int(randrange(ord('0'), ord('9') + 1)))
    return s

print('{:^21}'.format('Φ'), end='')
for i in range(0, 21, 2):
    print('{:^21}'.format(str(ranstr(i - 1))))
for i in range(4):
    print('{:^21}'.format(ranstr1(5)))
```

#### 📐 代码解析

##### 树冠生成(`ranstr`)
- 每行字符数从 1 递增到 19(步长 2)
- 字符从 `'A'` 到 `'z'` 的 ASCII 范围内随机选择(包含中间的特殊字符)

##### 树干生成(`ranstr1`)
- 每行 5 个随机数字(0~9)
- 共 4 行

##### 树的形状
- 树冠 10 层，长度为 **1, 3, 5, …, 19**（奇数递增，不是偶数）
- 顶上那颗 `Φ` 的下一"层"其实是空串（`ranstr(-1)`），被 `end=''` 吞进同一行，所以看不出空行
- 树干 4 层，每层 5 个随机数字
