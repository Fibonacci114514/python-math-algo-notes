# 寻找库路径.py · 揭示库的本质

> **摘要**:一行代码打印 `random` 模块对应的文件路径.它回答了初学者最常见的疑问之一——"库到底是什么？"答案是:库就是放在 Python 能找到的目录里的 `.py` 文件(或编译后的二进制扩展).

---

#### 💻 代码

```python
import random
print(random.__file__)
```

---

#### 📖 运行结果

**Windows 示例**:
```
C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\Lib\random.py
```

**macOS / Linux 示例**:
```
/usr/local/lib/python3.12/random.py
```

---

#### 📐 这行代码揭示了三件事

##### 1. 库有物理位置

`random.__file__` 返回的不是抽象概念,而是一个**真实的文件路径**.你可以用文件管理器直接打开它.

##### 2. 库就是 `.py` 文件

打开 `random.py`,你会看到里面就是一堆 `def` 定义的函数,`class` 定义的类,若干常量——**和你自己写的 `.py` 文件结构完全相同**,只是更长,更严谨.

##### 3. `import` 就是"找文件并执行"

`import random` 在 Python 眼里做的是:
1. 按 `sys.path` 的顺序搜索名为 `random.py` 的文件
2. 执行该文件的顶层代码
3. 把文件里定义的名字(函数,类,变量)暴露给调用方

---

#### 📐 如果输出的是 `.pyd` 或 `.so`

某些模块(如 `math`)的 `__file__` 会指向 `.pyd`(Windows)或 `.so`(Linux/macOS)文件.这说明它是 **C 扩展模块**,源码是 C 语言,编译成了二进制.但对外暴露的调用方式与纯 Python 模块完全一致——这就是 Python 被称为"胶水语言"的原因.

```python
import math
print(math.__file__)
# 可能输出: .../math.cp312-win_amd64.pyd
```

---

#### 📐 延伸实验

```python
import sys
print(sys.path)          # 查看 Python 的模块搜索路径

import random
print(random.__doc__)    # 查看模块的文档字符串
print(dir(random))       # 查看模块暴露的所有名字
```
