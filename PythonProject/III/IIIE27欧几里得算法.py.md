# `IIIE27欧几里得算法.py` · 最大公约数

> **摘要**:使用辗转相除法(欧几里得算法)求两个整数的最大公约数.

---

#### 💻 代码

```python
a = int(input())
b = int(input())
c = a % b
while c > 0:
    a, b = b, c
    c = a % b
print(b)
```

---

#### 📖 运行示例

**输入**:
```
48
18
```

**输出**:
```
6
```

---

#### 📐 数学原理

欧几里得算法基于:$\gcd(a, b) = \gcd(b, a \bmod b)$

**计算过程**:
```
48, 18 → 48 % 18 = 12
18, 12 → 18 % 12 = 6
12, 6  → 12 % 6 = 0 → 输出 6
```
