# VE3冒泡排序.py · 冒泡排序(带提前终止优化)

> **摘要**:冒泡排序是最基础的排序算法之一.通过反复比较相邻元素并交换逆序对,使较大的元素逐渐“浮”到列表末尾.本实现加入了提前终止优化:若某轮未发生任何交换,说明列表已有序,直接返回.

---

#### 💻 代码

```python
def Bubble_Sort(testlist):
    while True:
        errorcount = 0
        for i in range(len(testlist) - 1):
            if testlist[i] > testlist[i + 1]:
                testlist[i], testlist[i + 1] = testlist[i + 1], testlist[i]
                errorcount = errorcount + 1
        if errorcount == 0:
            return testlist

print(Bubble_Sort([14105, 81193, 41299, 6596, 83102, 92049, 55600, 61372,
                   37117, 60122, 17506, 20742, 71482, 68720, 62817, 1408,
                   94084, 61621, 98858, 52258]))
```

#### 📐 算法分析

##### 核心思想
- 每一轮从左到右扫描,比较相邻两个元素
- 若前者大于后者,交换它们
- 一轮结束后,最大的元素被“冒泡”到末尾
- 重复上述过程,直到某一轮没有任何交换发生

##### 时间复杂度

| 情况 | 时间复杂度 | 说明 |
| :--- | :--- | :--- |
| 最好 | $O(n)$ | 列表已有序,一轮扫描后 `errorcount == 0`,直接返回 |
| 最坏 | $O(n^2)$ | 列表完全逆序,需要 $n-1$ 轮,每轮 $n-1$ 次比较 |
| 平均 | $O(n^2)$ | — |

##### 空间复杂度
$O(1)$ —— 原地排序,只用了常数个额外变量(`errorcount`,`i`).

##### 稳定性
**稳定排序** —— 当 `testlist[i] == testlist[i+1]` 时不交换,相等元素的相对顺序保持不变.

---

#### 📐 代码拆解

| 语句 | 作用 |
| :--- | :--- |
| `while True:` | 无限循环,直到满足终止条件才返回 |
| `errorcount = 0` | 每轮开始时重置交换计数器 |
| `if testlist[i] > testlist[i+1]:` | 检测逆序对 |
| `testlist[i], testlist[i+1] = testlist[i+1], testlist[i]` | 元组解包交换,无需临时变量 |
| `errorcount = errorcount + 1` | 记录本轮交换次数(即逆序对数量) |
| `if errorcount == 0: return testlist` | 无交换 → 已有序 → 提前终止 |

> **补充**:`errorcount` 的值实际上等于当前列表中**逆序对**的数量.如果把它改成布尔值 `swapped`,逻辑一样,但语义更清晰,更轻量.

#### 🔧 可优化方向

##### 1. 布尔值替代计数器
```python
def bubble_sort(lst):
    n = len(lst)
    while True:
        swapped = False
        for i in range(n - 1):
            if lst[i] > lst[i + 1]:
                lst[i], lst[i + 1] = lst[i + 1], lst[i]
                swapped = True
        n -= 1          # 末尾已就位，缩小范围
        if not swapped:
            return lst
```
每轮结束后末尾元素已确定,下一轮无需再比较最后一个位置.

##### 2. 与选择排序的对比
| 对比项 | 冒泡排序 | 选择排序 |
| :--- | :--- | :--- |
| 交换次数 | 多(每次逆序都交换) | 少(每轮只交换一次) |
| 最好情况 | $O(n)$(已有序时) | $O(n^2)$(无论是否有序) |
| 稳定性 | 稳定 | 不稳定 |
| 适用场景 | 教学,近乎有序的小数据 | 交换成本高的场景 |
