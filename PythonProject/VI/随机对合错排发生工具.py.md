# `随机对合错排发生工具.py` · 错排 ∩ 对合

> **摘要**:在错排之上再叠一条约束——置换必须**对合**,即 $\sigma(\sigma(i)) = i$.两层拒绝采样:内层保证无不动点,外层保证两次映射回到原点.产物是"两两互不相交的对换之积",**它将被拿去构造恩尼格玛机的反射器模块**;变量名 `reflector`(反射器)即由此而来.

---

#### 💻 代码

```python
import random
def staggeredfunction(s):
    while True:
        staggerederrorcount=0
        random.shuffle(s)
        for i in range(len(s)):
            if i==s[i]:
                staggerederrorcount+=1
        if staggerederrorcount==0:
            return s
l=4
s=[x for x in range(l)]
s0=[x for x in range(l)]
while True:
    reflector={}
    reflectorerrorcount=0
    reflector=dict(zip(s0, staggeredfunction(s)))
    for i in range(l):
        if reflector[reflector[i]]!=i:
            reflectorerrorcount+=1
    if reflectorerrorcount==0:
        break
print(reflector)
```

---

#### 📖 运行示例

`l=4` 时**全部可能结果只有 3 种**,多跑几次就能看全:
```
{0: 1, 1: 0, 2: 3, 3: 2}    # (01)(23)
{0: 3, 1: 2, 2: 1, 3: 0}    # (03)(12)
{0: 2, 1: 3, 2: 0, 3: 1}    # (02)(13)
```

---

#### 📐 数学背景

**对合**:$\sigma^2 = \mathrm{id}$.再加上**无不动点**,合起来恰好是"互不相交的对换之积".

在 $2m$ 个元素上,这类置换的个数是双阶乘:

$$
(2m-1)!! = \frac{(2m)!}{2^m\, m!}
$$

| $2m$ | 个数 | 占全排列比例 |
| :--- | :--- | :--- |
| 2 | 1 | 1/2 |
| 4 | 3 | 3/24 = 1/8 |
| 6 | 15 | 15/720 ≈ 1/48 |

**两层拒绝的命中率可以相乘**:错排占 $D_4/4! = 9/24$,其中对合的占 $3/9$,总命中 $3/24 = 1/8$ —— 与直接枚举的结果一致.

---

#### 🧠 实现要点

| 点 | 说明 |
| :--- | :--- |
| 内层 `staggeredfunction` | 负责"错排",就地打乱 `s` 并返回同一个列表 |
| 外层 `while True` | 负责"对合":用 `reflector[reflector[i]] != i` 逐点检验 |
| `zip(s0, s)` | 把值域与定义域缝成键值对;`s0` 始终是原序,故不会受打乱影响 |
| `s` 被就地修改 | 调用方传进来的列表会被改写 —— 抽成模块被 `import` 时最容易踩 |
| `reflector={}` | 下一行立刻被 `dict(...)` 覆盖,是空赋值 |

---

#### ⚠️ 适用边界

- **$l$ 必须是偶数**.奇数阶不存在"无不动点的对合"(元素必须两两配对),此时外层永远退出不了,程序会**死循环**.
- $l=2$ 是退化情形,只有 `{0: 1, 1: 0}` 一种结果.
