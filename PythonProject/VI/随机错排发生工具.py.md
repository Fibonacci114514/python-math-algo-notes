# `随机错排发生工具.py` · 拒绝采样生成错排

> **摘要**:把一个列表反复随机打乱,直到没有任何元素停留在它原来的下标上,得到一个**错排**(derangement).这里用的是**拒绝采样**:先随便造一个候选,不合格就丢掉重造,直到合格为止.

---

#### 💻 代码

```python
import random
s=[0,1,2,3,4]
while True:
    errorcount=0
    random.shuffle(s)#打乱
    for i in range(len(s)):
        if i==s[i]:
            errorcount+=1
    if errorcount==0:
        break#检测是否错排
print(s)
```

---

#### 📖 运行示例

三回运行的结果(每次都不同):
```
[3, 0, 1, 4, 2]
[1, 4, 3, 0, 2]
[1, 4, 0, 2, 3]
```
逐项核对:任一下标 $i$ 上的值都不等于 $i$,即对一切 $i$ 有 $s_i \neq i$.

---

#### 📐 数学背景

错排计数给出的是**命中率**:

$$
D_n = n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}, \qquad D_5 = 44
$$

全排列共 $5! = 120$ 种,其中错排 44 种,所以每轮命中概率约 $44/120 \approx 36.7\%$.期望轮数 $\approx 2.7$,这就是"随机重试"在这个规模下很便宜的原因.

随着 $n$ 增大,$D_n/n! \to 1/e \approx 36.79\%$ —— **命中率不随规模衰减**,这是拒绝采样在这个问题上好用的关键.

---

#### 🧠 实现要点

| 点 | 说明 |
| :--- | :--- |
| `random.shuffle(s)` | **就地**打乱原列表,不返回新列表 |
| `while True` + `break` | 拒绝采样的标准骨架:无上限重试,由 `errorcount==0` 决定何时收手 |
| `errorcount` 计数 | 每轮必须在循环内**重新清零**,否则会累加上一轮的计数 |
| `s[i] == i` | 判定"不动点"的充要条件(这里列表值恰好等于下标) |
